### Не істей алады

| | |
|---|---|
| **Файлдар** | Файлдарды қол астында ұстау үшін ойыққа тастаңыз немесе сүйреп бара жатып меңзерді сілкіңіз, қалқымалы себет пайда болады |
| **Музыка** | Apple Music, Spotify және Яндекс Музыка мұқабалар, барыс, ән мәтіні және басқарумен, плеер терезесі жабық болса да |
| **Хабарлар** | Telegram мен WhatsApp хабарлары ойықтан шыны карточкалар болып шығады және сол жерде жауап бересіз |
| **Адамдар** | Таңдаулылар, белгілер мен желідегі күйі бар тірі чаттар, дауыстық хабарлар, үлгілер және кейінірек жіберу |
| **Виджеттер** | Алмасу буферінің тарихы, назар таймері, ауа райы, күнтізбе және басқалар |
| **Кез келген Mac** | Ойығы жоқ экрандарда арал ойық болатын жерде тұрады және меңзерді жоғарғы шетке тіремейінше жіңішке жолаққа жасырына алады |

Жаңартулар өзі келеді: бір басу, және сізде жаңа нұсқа.

### Орнату

1. [Releases](https://github.com/AbexLab/INT_Abex-Island_macOS/releases/latest) бөлімінен `.zip` файлын жүктеп алып, ашыңыз.
2. **Abex Island**-ды «Бағдарламалар» қалтасына жылжытып, сол жерден ашыңыз.
3. Алғаш рет қолданбаны Control пернесімен басып, **Ашу** таңдаңыз (немесе Жүйе баптаулары → Құпиялылық және қауіпсіздік → **Бәрібір ашу**).
4. Қолданба қажетті рұқсаттарды өзі сұрайды (Арнайы мүмкіндіктер, хабар хабарландырулары үшін Дискіге толық қол жеткізу) және әрқайсысын түсіндіреді.

### Күйі

Бұл **бета**: бірдеңе әлі бұзылуы мүмкін, әр пікір көмектеседі. Қате таптыңыз ба немесе идеяңыз бар ма? [Issue](https://github.com/AbexLab/INT_Abex-Island_macOS/issues) ашыңыз.

Windows нұсқасы әзірленуде.
