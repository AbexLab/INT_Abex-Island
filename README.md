### What it does

| | |
|---|---|
| **Files** | Drop files on the notch to keep them at hand, or shake the pointer while dragging to get a floating basket |
| **Music** | Apple Music, Spotify and Yandex Music with covers, progress, lyrics and controls, even when the player window is closed |
| **Messages** | Telegram and WhatsApp messages come out of the notch as glass cards, and you answer right there (on Mac) |
| **People** | Favourites, live chats with ticks and online status, voice messages, templates and sending later (on Mac) |
| **Widgets** | Clipboard history, a focus timer, weather, calendar and more |
| **Mac and Windows** | On a Mac the island lives in the notch; on displays without one, and on Windows, it sits at the top edge of the screen and can tuck into a thin strip |

Updates arrive by themselves: one click and you have the new version.

### Install on a Mac

1. Download the `.zip` from [Releases](https://github.com/AbexLab/INT_Abex-Island/releases/latest) and open it.
2. Move **Abex Island** to the Applications folder, and open it from there.
3. The first time, Control-click the app and choose **Open** (or System Settings → Privacy & Security → **Open Anyway**).
4. The app asks for the permissions it needs (Accessibility, Full Disk Access for message notifications) and explains each one.

### Install on Windows

1. [Download the `.zip` for Windows](https://github.com/AbexLab/INT_Abex-Island/releases/download/v1.0.0-beta.3/Abex-Island-1.0.0-beta.3-Windows.zip) and open **Abex Island.exe** from it.
2. Windows may say the publisher is unknown: choose **More info → Run anyway**.
3. Press **Install** in the welcome window: the app goes to the Start menu, opens at sign-in and updates itself. No administrator needed.
